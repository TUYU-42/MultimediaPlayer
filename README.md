## 專案簡介

C# .NET Framework WinForms 多媒體播放器，支援影片/音訊播放清單、播放控制、音量、進度列、循環播放、影片區域縮放與全螢幕播放。

## 執行方式

1. 使用 Visual Studio 2022 開啟 `MultimediaPlayer.sln`。
2. 確認目標框架為 .NET Framework 4.7.2。
3. 按下 `F5` 或點選「開始偵錯」執行。
